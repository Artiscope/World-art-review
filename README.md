# World Art Review

Discover Artists. Understand Art.

An editorial site of researched artist dossiers, artwork reviews, collecting guides and technique explainers. Starts with Zara Muse and Konn Artiss, and grows to cover the Grove Gallery artists.

## What is here

- `index.html`: the whole site in one file. The content lives in four lists at the top of the script (SOURCES, ARTISTS, ARTICLES, GUIDES). Add an entry to add an artist, artwork, article or source.
- `design/`: the design canvas files for the homepage and the Zara Muse dossier sample.
- `.github/workflows/pages.yml`: publishes the site to GitHub Pages on every push to `main`.

## Running it

Open `index.html` in a browser. There is no build step.

## Publishing

Pushes to `main` publish automatically to GitHub Pages. Turn Pages on once in the repository settings (Settings, then Pages, then set Source to GitHub Actions).

## House rules for the design

- Colours: Oatmilk #EEE5D4 for pages and cards (about 60%), Calm Green #1D4A35 for bands, buttons and labels (about 30%), brick #B5392B for links and highlights (about 10%). Text is charcoal #1D1D1B.

- Typefaces: Castoro for the name and headlines, Literata for reading text, Libre Franklin for small text and buttons. Logo and colours follow the World Art Review logo guidelines (version 2.0, November 2026).
- No long dashes, no long dividing lines, no spaced capital labels, no rounded corners.
- UK spelling throughout.
- Every fact in a dossier carries a numbered source. Claims that come only from publicity are marked Reported.
